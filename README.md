# Swami Vivekananda University Website

Responsive university admissions website for **Swami Vivekananda University, Barrackpore**.

## Tech Stack

- Next.js
- Tailwind CSS
- Lucide React icons

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Walkthrough Video Flow

1. Start on desktop view and show the hero, navigation, CTA, and campus media.
2. Scroll through About, Programs, Campus, Testimonials, CTA, and Footer.
3. Click the program category buttons to show the interaction.
4. Hover over gallery cards and CTA buttons to show transitions.
5. Switch to mobile responsive view and show the mobile menu plus full page scroll.

## Content Notes

The design, layout, and copy are original. Factual details such as location, establishment year,
program areas, campus amenities, and contact information were cross-checked from the official
SVU website:

- https://www.swamivivekanandauniversity.ac.in/know-us
- https://www.swamivivekanandauniversity.ac.in/infrastructure
- https://www.swamivivekanandauniversity.ac.in/schools
- https://www.swamivivekanandauniversity.ac.in/contact

Campus photos and the university logo are stored locally in `public/images` for a stable demo.
