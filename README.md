# SVU Barrackpore Website

A modern and responsive website built for SVU Barrackpore using Next.js and Tailwind CSS.
Designed with a clean interface, smooth navigation, and optimized performance for both desktop and mobile devices.

## Preview

Live Website: https://svu-zeta.vercel.app

## Tech Stack

* Next.js
* React
* Tailwind CSS
* TypeScript

## Features

* Responsive modern layout
* Smooth scrolling experience
* Optimized performance
* Mobile-friendly design
* Clean and minimal UI
* Fast loading with Next.js
